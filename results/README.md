# Results

Generated by the `seas` CLI; do not edit by hand.

* `RESULTS.md` — human-readable report (confirmatory hypotheses, secondary analyses, per-scenario tables).
* `CONFIRMATORY.json` — machine-readable evaluation of H1–H4 (preregistered in `docs/preregistration.md`).
* `<scenario>/runs.csv` — one row per run (scenario × sweep point × policy × seed) incl. the SHA-256 of
  its event trace; `summary.csv` (means, 95 % bootstrap CIs) and `pairwise.csv` (paired secondary tests).
* `<scenario>/config.resolved.yaml` — resolved scenario, input-file hashes, code commit, platform.
* `S1/base/{eft,seas}/seed_0/` — full event traces and decision records used by figures C and F.

Per-seed trace directories for all other runs are not committed (≈100 MB); `seas run` regenerates them
bit-identically (`seas verify` re-runs the first seed of every configuration and checks the hashes).

Confirmatory: S1, S4, S7. Exploratory: S2, S3, S5, E-load, scaling. Correctness: S6.
